# ime-week01-reflection
reflection assignment for ime programme

Nowadays AI tools like ChatGPT and Copilot can quickly generate large amounts of code. Many people think that human beings no longer need to learn programming by themselves. However, I believe programming knowledge is still very valuable for design students.

First of all, AI can produce code, but it cannot fully understand our real design goals. If I do not know basic programming logic, I cannot judge whether AI-generated results are reasonable. I will have no ability to find bugs or adjust functions for my product prototype. I can only passively accept whatever AI gives me. Research shows that generative code tools often produce syntactically correct code that fails to match the real design intent, and beginners without programming literacy cannot identify these hidden defects (Ahmed et al., 2025).

Secondly, learning programming helps me build logical thinking. As a product-design student, programming trains me to break complex user requirements into small, clear steps. This way of thinking improves my user-research and prototyping ability, even when I am not writing code. When I collaborate with engineers, basic programming knowledge helps me communicate design constraints and evaluate technical feasibility instead of only handing over static visuals.

AI is a powerful assistant, but not a replacement for designers. We can use AI to improve efficiency, yet basic programming literacy lets us take control of our own projects. Without this knowledge, we cannot communicate well with technical partners or evaluate technical feasibility for our design ideas. Studies on AI-assisted design education also point out that designers act as reviewers and curators of AI outputs; human critical judgment remains irreplaceable even with powerful code-generation tools (Ma et al., 2025).

In conclusion, AI changes how we create, but it does not remove the need for us to understand underlying logic. For me, learning programming is a way to better use AI tools and realise my product-design ideas. Generative AI lowers the barrier of writing code, but it raises the requirement for designers to verify, critique and direct computational outputs.
